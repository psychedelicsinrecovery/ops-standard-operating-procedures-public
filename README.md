**Psychedelics In Recovery™ (PIR®)** writes down how its approved work gets done, step by step, so any trusted
servant (or the helper they bring) can do it without the author in the room. A **proposal** asks for a decision; a
**procedure** (an SOP) says how an approved thing is done. This is the public side of PIR®'s procedures.

## 📭 What's public here

**Nothing yet, on purpose.** Procedures are drafted privately and stay private until an officer decides one is ready
for visitors. The list of what may appear here is a file in the private repository, `PUBLIC-ALLOWLIST.txt`, and
**it is empty**. When an officer adds a path to it, that procedure (and its PDF) is copied here automatically, after
a check that nothing private travels with it.

| When this page changes | What you'll see |
|---|---|
| An officer adds a procedure to the allowlist | its Markdown in a department folder (`OPS/`, `IT/`, `GOV/`…) and its PDF under `pdf/` |
| An approved version is tagged (`v1.0.0`…) in the private repository | the copy here says which version it is |

## 🗄️ The private side

This repository is a filtered copy of PIR®'s private `ops-standard-operating-procedures`, published by an allowlist
and never edited by hand. Drafts, the repository legend and anything with personal details stay private. Members
can read the private procedures by signing in to GitHub; to ask for access, type `/github` in
[PIR®'s Discord](https://discord.gg/MyprTq8w95) or use the
[web helpdesk](https://psychedelicsinrecovery.github.io/alex-desk-public/portal.html).

<sub>Changes here arrive only by the sync from the private repository (SOP-OPS-001, *How a change travels*).</sub>
