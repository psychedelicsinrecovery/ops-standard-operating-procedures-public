**Psychedelics In Recovery™ (PIR®)** writes down how its approved work gets done, step by step, so any trusted
servant (or the helper they bring) can do it without the author in the room. A **proposal** asks for a decision; a
**procedure** (an SOP) says how an approved thing is done. This is the public side of PIR®'s procedures: the ones every
organisation in the family shares, each beside its PDF.

## <img src="assets/icons/folder-lock.svg" width="24" height="24" alt=""> The private side

This repository is a copy of chosen pages from PIR®'s private `ops-standard-operating-procedures`, published by an
allowlist after a tripwire that reads every file (PDFs included) and never edited by hand. Drafts, the repository
legend and anything with a person's details stay private. Members read the private procedures by signing in to GitHub;
to ask for access, type `/github` in [PIR®'s Discord](https://discord.gg/MyprTq8w95) or use the
[web helpdesk](https://psychedelicsinrecovery.github.io/alex-desk-public/portal.html).
